## 📊 Уровни логирования

### DEBUG (отладочные)
- Запросы к БД с параметрами
- Детали операций
- Успешные рутинные операции

```python
logger.debug(f"📖 Запрос вопросов: profession_id={profession_id}, page={page}")
logger.debug(f"✅ Получено {len(questions)} вопросов")
logger.debug(f"✅ Пользователь аутентифицирован: {user.email}")
```

### INFO (информационные)
- Создание/обновление/удаление записей
- Важные события (вход, регистрация)
- Начало/конец операций

```python
logger.info(f"📝 Создание вопроса для профессии ID={profession_id}")
logger.info(f"✅ Вопрос создан: ID={question_id}")
logger.info(f"🎯 Создание сессии для профессии ID={profession_id}")
logger.info(f"✅ Сессия создана: ID={session_id}")
```

### WARNING (предупреждения)
- Неверные попытки входа
- Отсутствие данных
- Подозрительная активность

```python
logger.warning(f"⚠️  Попытка доступа без токена")
logger.warning(f"⚠️  Неверная попытка входа для: {email}")
logger.warning(f"⚠️  Вопрос не найден: ID={question_id}")
logger.warning(f"⚠️  Нет вопросов выбранной сложности {difficulty}")
```

### ERROR (ошибки)
- Ошибки операций
- Исключения

```python
logger.error(f"❌ Ошибка импорта вопроса #{idx}: {e}", exc_info=True)
logger.error(f"❌ Ошибка импорта данных: {e}", exc_info=True)
```

```logql
{job="it-interview-trainer"} |= "ERROR"

{job="it-interview-trainer"} | json | logger =~ ".*auth.*"
```

### В файле логов

```bash
# Последние 100 строк
tail -100 logs/app.log

# Только ошибки
grep "ERROR" logs/app.log

# Только предупреждения
```
