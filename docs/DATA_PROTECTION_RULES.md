## Новый функционал: Настройка собеседования

### Поток пользователя:

1. **Главная страница** → "Начать сессию"
2. **Выбор профессии** → Клик на профессию (DevOps, Frontend, etc.)
3. **Настройка собеседования** (`/interview/:professionId/setup`):
   - Выбор тем (категорий) ✓
   - Количество вопросов для каждой темы ✓
   - Уровень сложности (Intern/Junior/Middle) ✓
   - Сохранение конфигурации ✓
4. **Начать собеседование** → Сессия с выбранными вопросами

### Страницы:

- `/session/new` — Выбор профессии (только список профессий)
- `/interview/:professionId/setup` — Настройка собеседования (темы, количество, сложность)
- `/session/:id` — Прохождение собеседования

## Как добавлять вопросы

Вопросы добавляются ТОЛЬКО через:

1. **Админ-панель** (`/admin`)
   - Ручное создание через UI
   - Импорт из JSON/CSV

2. **API endpoints**
   - `POST /api/questions/` - создание одного вопроса
   - `POST /api/questions/import/json` - импорт из JSON
   - `POST /api/questions/import/csv` - импорт из CSV

3. **Прямое редактирование БД** (только для экстренных случаев)

## Что делает init_database.py

Скрипт `scripts/init_database.py` создаёт ТОЛЬКО:

- ✅ Администратора (admin@example.com / admin123)
- ✅ Профессии (4 штуки)
- ✅ Категории для вопросов
- ✅ Достижения (achievements)

**ВОПРОСЫ НЕ СОЗДАЁТСЯ!**

## Backup вопросов

Резервные копии хранятся в `/backups/`:

- `questions_fixed_100_devops.json` - текущий backup (105 вопросов)
- `questions_latest.json` - предыдущий backup

### Создать backup

```bash
cd backend
source venv/bin/activate
python3 ../scripts/export_questions.py
```

### Восстановить из backup

```bash
cd backend
source venv/bin/activate
python3 ../scripts/restore_questions.py
```
